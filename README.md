# Project Setup Overview

This repository contains three assessment tasks. Install only what is needed for each task.

## Task 1 setup
What you need installed:
- Python 3.14+ (or use the project virtual environment)
- Python package: openpyxl

Install command:
```bash
py -m pip install openpyxl
```

## Task 2 setup
What you need installed:
- SQLite-compatible SQL runner (for example SQLite CLI or DB Browser for SQLite)

No additional language packages are required for this task.

## Task 3 setup
What you need installed:
- Node.js and npm
- Playwright browsers
- npm package dependencies from package.json

Install commands (run from task 3 folder):
```bash
npm install
npx playwright install
```

## Shared resources
All tasks use input files in the resources folder (CSV, DB, and logs).
